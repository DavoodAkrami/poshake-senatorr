# Senatorr storefront

Premium Next.js storefront for the Senatorr menswear collection.

## Features

- Responsive home page and product catalog
- Search, category filters, and sorting
- Shopping bag saved in the current browser
- Instagram enquiry link for current prices and availability
- Nine regenerated product photographs in `public/products`

## Run locally

```bash
npm install
npm run dev
```

Prices, sizes, location, and other store details are intentionally left to direct Instagram enquiries because they could not be independently verified.
